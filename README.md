# Концентратор КС3
Встроенное ПО концентратора КС3.  

Концентратор выполняет опрос блоков измерения РАС-3к-М22 (далее "БИ"), принимает данные от БИ и передает на ВУ.

* **МК:** LPC4337-M4
* **Плата:** ks3
* **Среда разработки:** MCUXpresso, GCC


----
## Описание проекта

### Функции
- опрос блоков измерения по RS485
- передача данных на ВУ по Ethernet по протоколу UDP

### Структура проекта

```
lwip/                       # LwIP
lpc_chip_43xx/              # Драйверы периферии МК
src/                        # Исходные тексты c/cpp

  ├── protocol/             # Прикладной уровень реализации протокола обмена с ВУ и НУ
  ├── protocol_app/         # Протокол - интерфейс между уровнем приложения и обработчиком пакетов DataIO
  ├── startup/              # startup и начальное конфигурирования МК
  ├── supervisor/           # Управление выполнением задач и поддержка сообщений
  └── udp_io/               # Прикладной уровень работы с UDP
inc/                        # Заголовочные файлы
  ├── cfg/                  # Настройки и определения для конфигурирования программы
  ├── port/                 # Адаптация к нижнему уровню МК
  ├── dataio/               # Протокол DataIO - типы, константы, разбор/формирование пакетов нижнего уровня
  └── test/                 # Код для тестирования. Формирование данных измерения в режиме имитации.
```

## Описание реализации

### Реализация основного функционала

#### Опрос блоков измерения
Опрос блоков измерения и обработка входящих сообщений выполняется в модулях:

`p_slave_poll.h`  
Объект `SlavePoll` - автомат опроса ведомых устройств. Периодически формирует запросы, обрабатывает сообщения с блоками данных и передает данные в прикладной обработчик. Посылает подтверждения приема блоков данных.

`p_slave_data_io.cpp`  
Управление автоматом опроса - инициализация, пуск, останов. При приеме сообщений от ведомого устройства вызывает соответствующие обработчики автомата. При приеме данных записывает блок в контейнер блоков данных.

`p_slavemsghandlers_local_inst.cpp`  
Прикладные обработчики входящих сообщений от ведомых устройств. Далее вызывают обработчики из `p_slave_data_io.cpp`.

Цепочка обработки входящих сообщений от ведомых устройств:  
`protocol/p_slavemsghandlers_local.cpp` -> `p_slavemsghandlers_local_inst.cpp` -> `p_slave_data_io.cpp` -> `SlavePoll`

Запросы к ведомым устройствам формируются объектом типа `TMasterTx`. Через интерфейс в `Protocol::` (`addTxMsgWrite()`, `addTxMsgRead()`, `addTxMsgApp()`, `addTxMsgReadBlock()`) формируются объекты типа `TTxRequest`, которые помещаются в очередь исходящих запросов. `TMasterTx` выбирает запросы из очереди, формирует пакеты и передает в интерфейс связи. Периодический вызов автомата `Protocol::MasterTxLocal.process()` выполняется в `TaskMonitor::process()`.

Адреса устройств для опроса задаются в массиве `setup3.slaves[]`. Автомат опроса циклически формирует запросы по всем значениям в slaves[], кроме равных 0.
 
#### Буферизация принятых данных
Принятые данные сохраняются в объекте `TDataBuffersContainer buffers` (data_buffers.cpp). Объект содержит массив буферов (блоков) данных `DataIO::TDatabuffer` и методы для записи, чтения и удаления блоков.

#### Передача на ВУ
`data_buffers.cpp`  
Содержит контейнер блоков данных и обработчики входящих сообщений от ВУ. Выполняет обработку сообщений:
- Запрос данных. При наличии, передает блок данных из контейнера.
- Подтверждение приема блока данных. Удаляет из контейнера соответствующий блок.

`p_extMsgAppTypeHandler.cpp`  
Транслирует сообщения из `protocol/p_slavemsghandlers_hiio.cpp` в обращения к обработчикам в `data_buffers.cpp`. При обработке сообщения с запросом данных, сначала проверяет наличие данных в контейнере БД. При отсутствии посылает сообщение об отсутствии данных. 

#### Реализация протокола на уровне прикладной программы

```
src/
  ├── protocol/
      ├── protocol.cpp                  # Объекты реализации протокола для ВУ и НУ + интерфейс к ним
      ├── p_tmastertx.cpp               # Автомат передачи исходящих сообщений для НУ
      ├── p_slavemsghandlers_hiio.cpp   # Обработчики входящих сообщений от ВУ
      └── p_slavemsghandlers_local.cpp  # Обработчики входящих сообщений от НУ
```

### Хранение настроек
Настройки содержатся в структурах setup1, setup2, setup3. 

**setup1**
- серийный номер

**setup2**
- сетевой адрес для связи с ВУ
- сетевой адрес RS485-1
- сетевой адрес RS485-2
- RS232 baud
- RS485-1 (X4/X5) ISO baud
- RS485-2 (X6) baud
- IP адрес устройства
- Gateway IP
- Subnet IP mask
- локальный порт UDP для приема входящих пакетов
- удаленный порт UDP для отправки пакетов

**setup3**
- массив сетевых адресов блоков измерения

Доступ к конифгурации на чтение и запись выполняется по каналу связи через соответствующие регистры или через консоль. Конифгурация сохраняется в EEPROM МК и загружается при старте программы.


### Адаптация LwIP
Адаптация стека LwIP содержится в файлах:
- `src/lpc_phy_smsc87x0.c` - драйвер EMAC
- `lwip/src/arch/lpc18xx_43xx_systick_arch.c` - получение системного времени

В `lpc18xx_43xx_systick_arch.c` отключен код управления Systick timer. Переменная systick_timems, используемая в LwIP, инкрементируется в `hal.cpp::SysTick_Handler()`.
